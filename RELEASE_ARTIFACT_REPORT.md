## 4. Official GitHub Release Creation Protocol

1. Ensure secrets are populated in repository settings:
   - `ANDROID_KEYSTORE_BASE64`
   - `ANDROID_KEYSTORE_PASSWORD`
   - `ANDROID_KEY_ALIAS`
   - `ANDROID_KEY_PASSWORD`
   - `WINDOWS_CERTIFICATE_BASE64` (Optional for signed Windows)
   - `WINDOWS_CERTIFICATE_PASSWORD` (Optional for signed Windows)
2. Tag and push release version:
   ```bash
   git tag v1.0.0
   git push origin v1.0.0
   ```
3. GitHub Actions `publish-release` job will:
   - Compile all 3 platform matrix jobs in parallel.
   - Verify signatures.
   - Collate all binaries into `release-bundle/`.
   - Calculate real SHA-256 checksums into `SHA256SUMS.txt`.
   - Publish official release `BIO HI TECH LIMS v1.0.0` with actual attached binaries.
