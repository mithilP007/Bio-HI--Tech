BIO HI TECH LABORATORY - Patient Test Report App
================================================
HOW TO USE
1. Unzip the folder.
2. Double-click index.html (opens in Chrome / Edge / Safari).
3. New Report -> enter patient details -> click tests -> type values -> Save / Save & Print.
4. Saved Reports -> search by date or name, Mark Paid, Print, Edit.
5. Prices -> change normal / discount price, add or delete tests.

NOTES
- Everything is saved in the browser on this computer (not on a server).
  Use the same browser each time. Clearing browser data erases reports.
- The QR code on the report needs an internet connection when printing.
  The barcode and the rest of the report work offline.
- Print with "Background graphics" turned on, A4 paper, margins None.
